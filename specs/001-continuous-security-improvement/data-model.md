# Data and evidence contracts

No new database/store or persisted model. Existing facts contain source-bound observations; ledger
attack classes derive from those observations. Source, detector and report digests stay distinct.

- Flow occurrence: sink/file/line, bounded source/assignment trace and unsupported-work gaps.
- Route: literal method/path, source registration and spec provenance; docs alone are not handlers.
- Control: exact invocation/returned value and supported enforcing scope; unknown wrappers,
  shadowing and mutation cannot become protection from names alone.
- Calibration: reviewed boolean labels with identity/provenance; authored pairs remain separate.
  Unknown rows cannot qualify a class as fully reviewed.
- Reconciliation: immutable workstream IDs, evidence, delivery state and limitations. Only
  `docguard specs --write` generates registry observed digests.
