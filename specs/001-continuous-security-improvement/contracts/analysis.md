# Analysis and release contract

Recon remains offline and never imports/executes target snippets. Shared readers enforce root
containment, exclusions and budgets. Unresolved operations remain leads/gaps, not safety claims.
Use existing FACTS/ledger schema 2.0 and documented gate policy/exit precedence.

Changed detectors need unsafe, safe, unsafe-sibling, scope/reassignment and literal/comment controls
as applicable. Test producer-to-ledger mappings with real CLI runs in owned temporary directories.
Document corrected contracts where old assertions pinned unsafe over-suppression; do not remove
coverage to obtain green tests. Probe writes stay localhost-only at every transport.

Optional tooling, schedules, engine upgrades and live testing are distinct opt-ins. No automatic
adoption is introduced. Published distributions are independently verified after normal CI merge.
