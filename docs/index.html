websec-validator
v0.18.0 · MIT · Python 3.11+

The deterministic half of a pentest.

It reads a repository the way a senior pentester reads it on day one, then hands your AI coding agent the plan: what the attack surface is, which findings are real, and exactly what to test. No model inside, no server, no running app.

Try it

pip install websec-validator
websec run ./your-repo

Artifacts land in websec-out/: a briefing written for your agent, the structured recon, a de-duplicated findings ledger, SARIF 2.1.0, and probe scripts pre-filled with the endpoints it found. It never edits your repository.

What makes it different

  • It says when it could not look. Exit 3 means the picture is incomplete, and it outranks a clean result.
  • No model in the tool. Same repository, same output, every run.
  • Zero runtime dependencies. It shells out to the scanners you have installed and never imports them.
  • Nothing leaves your machine. The default pass makes no network calls at all.
